# GLPI Docker Manager

Install and manage GLPI on Linux from an interactive menu, using official Docker
images and an interface available in Spanish and English.

Version **1.0.2** · [MIT license](LICENSE)

![GLPI Docker Manager administration menu in Spanish](docs/images/main-menu-es.png)

*Main menu with demonstration data.*

[Watch the video tutorial (Spanish)](https://youtu.be/o93phEdGLJM)

## What you can do

- Choose a GLPI version and configure the IP, ports, timezone and credentials.
- Use HTTPS with a local CA, Let's Encrypt or your own certificates.
- Update GLPI and migrate to the next branch with a backup and rehearsal first;
  update MySQL patches and the Caddy proxy separately.
- Create manual or scheduled backups, restore them and move to another server.
- View services and logs, manage MySQL exposure and free disk space.
- Install the Linux agent on other computers using a command generated by the manager.

## Quick start

You need a Linux server with **sudo/root** access. The wizard checks requirements
and offers to install Docker and missing dependencies.

```bash
git clone https://github.com/solqubit/glpi-docker-manager.git
cd glpi-docker-manager
chmod +x start.sh
sudo ./start.sh
```

Choose your language and follow the wizard. When installation finishes, it shows
the GLPI URL and sign-in instructions. Change GLPI's initial passwords after
signing in.

Use **↑ / ↓** to move, **Enter** to select and **Esc** to go back.

## After installation

You can reopen the menu from the project folder:

```bash
sudo ./start.sh
```

Or from any directory, using the installed manager:

```bash
sudo /opt/glpi-docker-manager/start.sh
```

Both options manage the same installation and preserve its data.

Configuration, managed data, certificates and backups are stored under
**`/opt/glpi-docker-manager/`**, outside the downloaded repository.
